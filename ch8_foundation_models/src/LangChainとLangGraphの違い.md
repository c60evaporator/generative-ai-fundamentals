# LangChainとLangGraphの違い

LangChainとLangGraphは違いが分かりづらく、併用されることも多いですが、概ね以下のように役割が分けられています。

- **シンプルなタスク**（シーケンス図や）を**LLM中心**で実行するプログラムを実装
- **複雑かつ自律的なワークフロー**（状態管理図が必要となる）を**LLMを1コンポーネントとみなして**実行するプログラムを実装

||LangChain|LangGraph|
|---|---|---|
|主眼|シンプルなLLMアプリケーション|LLMを含む自律的なワークフロー|
|処理実行の中心|Agent（LLM）|複数のNode（LLMを含む多様なコンポーネント）|
|制御|呼び出しの連鎖（Chain）|状態遷移（Graph）|
|設計に適した図|シーケンス図、フローチャート|状態管理図|
|履歴保持の単位|thread (checkpointer)|thread + 長期記憶 (store)|
|得意なアプリケーション|チャットボット、RAG、単純Agent|協調Agent、Deep Research、複雑な業務フロー|
